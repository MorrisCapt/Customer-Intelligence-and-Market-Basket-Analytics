## Part A — Customer Segmentation (RFM Analysis)

### Problem Statement

An automobile parts manufacturing company collected 3 years of transaction data across 89 customers in 19 countries. Without an in-house data science team, they needed an external consultant to uncover customer buying patterns and design targeted marketing strategies.

### Dataset — `Sales_Data.xlsx`

| Property | Value |
|----------|-------|
| Records | 2,747 transactions |
| Columns | 20 features |
| Time Period | January 2018 – May 2020 |
| Countries | 19 |
| Unique Customers | 89 |
| Product Lines | Motorcycles, Classic Cars, Vintage Cars, Trucks & Buses, Planes, Ships, Trains |

**Key Columns:**

| Column | Description |
|--------|-------------|
| `ORDERNUMBER` | Unique order identifier |
| `QUANTITYORDERED` | Number of items in the order |
| `PRICEEACH` | Unit price of the item |
| `SALES` | Total revenue for the order line |
| `ORDERDATE` | Date of the order (stored as Excel serial integer) |
| `DAYS_SINCE_LASTORDER` | Days elapsed since the customer's previous order |
| `STATUS` | Order status: Shipped, Cancelled, In Process, etc. |
| `PRODUCTLINE` | Product category |
| `CUSTOMERNAME` | Customer entity name |
| `COUNTRY` | Customer country |
| `DEALSIZE` | Deal size category: Small, Medium, Large |

### Approach

#### 1. Exploratory Data Analysis
- Univariate analysis of sales, quantity, deal size, and product line distributions
- Bivariate analysis: average sales by product line, revenue by deal size
- Temporal trend analysis across weekly, monthly, quarterly, and yearly granularities
- Multivariate heatmap of revenue across product lines and quarters
- Top customers and country-level revenue breakdowns

#### 2. RFM Analysis

**RFM** (Recency, Frequency, Monetary) is a proven customer segmentation framework:

| Metric | Definition |
|--------|-----------|
| **Recency (R)** | Days since the customer's most recent purchase |
| **Frequency (F)** | Total number of distinct orders placed |
| **Monetary (M)** | Cumulative revenue generated by the customer |

**Scoring:** Each metric is divided into 4 quartile-based bins (scores 1–4). For Recency, a lower number of days earns a higher score.

#### 3. Customer Segments

| Segment | RFM Total Score | Characteristics |
|---------|----------------|-----------------|
| 🏆 **Best Customers** | ≥ 10 | Recent, frequent, high spenders |
| 💙 **Loyal Customers** | 7–9 | Regular buyers with moderate spend |
| ⚠️ **At Risk / Verge of Churning** | 5–6 | Previously active, now going quiet |
| 🔴 **Lost Customers** | ≤ 4 | Inactive, infrequent, low spend |

## Part B — Market Basket Analysis

### Problem Statement

A grocery store provided POS transactional data spanning 20 months. The objective was to identify the most commonly co-purchased sets of items and recommend product combos, bundle offers, and discount strategies to increase store revenue.

### Dataset — `dataset_group.csv`

| Property | Value |
|----------|-------|
| Records | 20,641 product-order rows |
| Columns | 3 (Date, Order_id, Product) |
| Time Period | January 2018 – August 2019 |
| Unique Orders | 1,139 baskets |
| Unique Products | 37 grocery items |

### Approach

#### 1. Exploratory Data Analysis
- Product frequency ranking (most and least purchased items)
- Basket size distribution (items per order)
- Monthly, quarterly, and day-of-week order volume trends
- Product co-occurrence heatmap for the top 15 items

#### 2. Association Rule Mining — Apriori Algorithm

Association rules take the form:  
> *If a customer buys **{A}**, they are also likely to buy **{B}**.*

**Key Metrics:**

| Metric | Formula | What it Means |
|--------|---------|---------------|
| **Support** | freq(A∪B) / N | How often the combination appears across all baskets |
| **Confidence** | freq(A∪B) / freq(A) | How reliable the rule is — given A, how likely is B? |
| **Lift** | Confidence / P(B) | How much more likely B is given A vs. buying B at random. Lift > 1 = positive association |

**Thresholds Used:**

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Minimum Support | 5% | Itemset must appear in ≥ 57 of 1,139 baskets to be considered significant |
| Minimum Confidence | 30% | Rule must be correct at least 30% of the time |
| Minimum Lift | 1.0 | Only positive associations are retained |

#### 3. Recommendations

Business strategies derived from the rules include:
- **Bundle Discounts** (10–15% off) for the highest-lift product pairs
- **Cross-Aisle Shelf Tags** directing customers from one product to its frequent companion
- **Buy 2 Get 1 Free** promotions built around 3-itemset rules
- **Themed Meal Kit Bundles** grouping frequently co-purchased items
- **In-App Smart Suggestions** when a product is added to a digital cart
- **Weekend Flash Combos** and **Loyalty Double Points** for co-purchased pairs

## Getting Started

### Prerequisites

- Python 3.8 or higher
- pip

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/customer-intelligence-market-basket-analytics.git
cd customer-intelligence-market-basket-analytics
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Place the Data Files

Ensure the following files are placed in the `data/` directory:

```
data/
├── Sales_Data.xlsx
└── dataset_group.csv
```

> **Note:** The data files are not included in this repository due to proprietary restrictions. Place them in the `data/` folder before running the notebooks.

### 4. Launch Jupyter

```bash
jupyter notebook
```

Then open either notebook from the `notebooks/` folder:
- `Part_A_Customer_Segmentation_RFM.ipynb`
- `Part_B_Market_Basket_Analysis.ipynb`

> Each notebook reads data from the `data/` directory relative to the project root. If running notebooks from within the `notebooks/` folder, update the file paths accordingly (e.g., `../data/Sales_Data.xlsx`).

## Results & Key Findings

### Part A Highlights

- **Classic Cars** dominate order volume (~40% of all orders); **Trains and Ships** generate the highest average revenue per order.
- **Q4** consistently records the highest seasonal sales spike across all years.
- **USA** is the single largest market, followed by Spain and France.
- **Medium deal sizes** generate the greatest share of total revenue despite being outnumbered by small deals.
- RFM segmentation identified clear tiers of customers — a small group of Best Customers drives disproportionately high revenue.

### Part B Highlights

- **Poultry, Soda, and Cereals** are the most frequently purchased products.
- Average basket size is ~18 items per order.
- The Apriori algorithm revealed strong product associations with lifts well above 1.0 — confirming non-random co-purchase behaviour.
- Top recommended combos and their discount strategies are detailed in the notebook and exported to `outputs/Association_Rules_Results.csv`.
